# 回归测试与实机验收

扩展已有 `MediaActionResolverTests`、`MediaActionPlaybackTests`、`MediaResourceStateStoreTests`、`MediaActionsUITests`、`QueueManagerTests`、`PlaybackCoordinatorQueueTests`、`QueuePaginationTests` 及窗口/性能相关套件。测试名以 MAS-Rxx 标识；不得删除旧测试。使用 controllable mock、continuation/barrier、确定性 RNG 和 clock，禁止靠随机 sleep 保证竞态顺序。纯函数测试之外必须覆盖实际 controller/dispatcher → coordinator/provider → store → UI 接线；必要时抽薄可测试入口，不新增并行业务系统。

| ID | 验收场景 | 必须断言 |
|---|---|---|
| R01 | Provider 能力变化 | 菜单与一级控件读取同一能力；执行再校验；无硬编码第二来源 |
| R02 | 未认证/权限变更 | 不发无权写入；显示真实原因；播放登录引导不假成功 |
| R03 | catalog/library ID 不同、缺失 | 正确映射；缺证据不删除；别名不串资源 |
| R04 | 自建、协作、未知归属歌单 | 所有容器写路径拒绝，Provider 调用数零 |
| R05 | 平台歌单移除 | 仅已证实订阅关系；错误 ownership/ID 拒绝 |
| R06 | 收藏部分 receipt | 已知资料库字段保留 |
| R07 | 入库部分 receipt 与新收藏 pending | 不清除其他字段意图 |
| R08 | 两次快速切换均失败 | 回滚真实 confirmed，不回滚 pending |
| R09 | 前写成功后新写失败 | 真实前次确认保留；旧 feedback 不出现 |
| R10 | 待执行旧意图被取代 | 允许合并未执行同字段写；明确 superseded |
| R11 | 旧 GET 在新写确认后返回 | 不能覆盖字段新 revision |
| R12 | 超时核对等待期间新操作 | 旧核对不提交新状态；正确处理服务器可能已执行 |
| R13 | 超时且读回不同目标 | 不是成功；反映真实状态 |
| R14 | 超时且读回失败/缺字段 | unknownOutcome；不盲重试、不伪造 false |
| R15 | 合并读取多个等待者 | 相同合并结果；无重复请求、旧 raw value 不外泄 |
| R16 | A→B→A/同账号新 generation | 旧 read/write/seed/feedback 均不提交或清理新 task |
| R17 | 缓存超限及完成任务 | pending 不淘汰；辅助字典有界，结束后释放 |
| R18 | 多界面同资源 | 详情、卡片、队列状态同步；局部更新，不改队列 |
| R19 | 350首集合多个页面入口 | 卡片/详情菜单/详情右键同一完整集合与来源 |
| R20 | 全量随机含350首 | 首曲随机、无遗漏/非法去重；未完整不得提交随机 |
| R21 | 点击第 N 行/右键单曲 | occurrence 精确、集合后续顺序与仅单曲语义不同 |
| R22 | 五种播放意图 | 按 RULES 的 A/B/C/D 与 X/Y/Z 矩阵，模式和历史正确 |
| R23 | 艺人慢请求 vs 新专辑 | 后发意图胜，旧请求不能变更队列 |
| R24 | 电台慢请求 vs 新歌曲 | 旧电台不得中断新歌曲或取消其分页 |
| R25 | 旧专辑完成时新分页已启动 | 旧 cancel/commit 无副作用 |
| R26 | 两次追加等待中替换/清空 | 原目标失效则拒绝，不重新捕获新队列 |
| R27 | 同会话连续追加/插入乱序返回 | 按发起顺序提交、批次内保序，重复歌曲独立 UUID |
| R28 | 会话变化发生在 UI guard 与 actor 提交间 | 协调器原子拒绝，旧队列/资源不泄漏 |
| R29 | 分页失败/游标循环/100页上限 | 不声称完整，正确错误与重试；随机不提交部分 |
| R30 | 渐进批次边界（若实现） | 已消费锚点、追加、清空、重试、等待边界均保序且不复活 |
| R31 | Engine 播放失败但 acceptedCount>0 | 仅准备/失败，不显示已播放；历史不虚假推进 |
| R32 | 电台切换确认 | 不可混入普通队列；取消无副作用；文案与真实行为一致 |
| R33 | 平台写入/删除与播放并行 | 不主动中断音频、不改队列及来源；不可用曲目正常失败 |
| R34 | 目录/资料库专辑及来源导航 | 作用域完整、目的地去重、合作艺人选择正确 |
| R35 | 艺人头部/卡片/右键 | 同一热门歌曲选择，无 topSongs 时无伪播放 |
| R36 | 初始未知收藏/资料库状态 | 有实际查询才显示查询中；失败可恢复；不默认 false |
| R37 | 空/禁用菜单与过期目标 | 无播放、无写入；切换页面或账号不能操作旧目标 |
| R38 | 队列拖拽/删除/菜单/分页错误 | 可见准确反馈；不双报、不吞异常 |
| R39 | 菜单关闭/失焦/窗口隐藏/销毁 | 无悬挂 panel/monitor，旧 completion 不干扰新菜单 |
| R40 | 快速键盘/鼠标反转/双击选择 | 最多一次业务意图；焦点与可见命中一致 |
| R41 | 多显示器及小窗口 | 菜单位于可见屏幕，降级仍可操作 |
| R42 | 50次队列操作和菜单切换 | 真实队列无丢项；视觉反馈、图层、任务有界 |
| R43 | 状态栏恢复及退出 | 仅恢复目标舞台，Normal/Mini/模块状态不被重置；退出持久化 |
| R44 | 旧快照与新关系字段 | 正确兼容，账户隔离，电台资源 ID 恢复正确 |
| R45 | 旧队列全量回归 | 随机、循环、清空、历史、失败重试、分页、撤销、恢复均通过 |

## 真实环境验收（不得用 Mock 替代）
- E01 歌曲/专辑/平台歌单逐类型资料库添加/移除、收藏/取消及读回；E02 艺人收藏、歌曲/艺人电台；E03 真实 ID 映射及个人歌单保护（只用非破坏性证据）；E04 大型歌单真实分页与失效、账户切换、真实引擎错误和恢复。
- E05 macOS Original/Enhanced 原生菜单实际视频/截图与连续几何、键盘、VoiceOver、Reduce Motion/Transparency；E06 多屏、失焦、关闭、状态栏恢复。
- E07 Instruments 基线对照及 App/WebKit 内存、主线程、任务/监听数量、100/1k/10k 条目与长时间运行，按 UI_PERFORMANCE 协议。

基线命令建议：`git status --short`、`git rev-parse HEAD`、`swift --version`、`xcodebuild -version`、`cd AirMuse_macOS && swift test`（以真实 package/SDK 为准），定向 `swift test --filter <实际套件>`；若仓库提供正式构建脚本优先复用。记录每次命令、退出码、实际通过/失败/跳过数量、日志/trace 位置；禁止把仓库已有自报结果写成本轮实测。
