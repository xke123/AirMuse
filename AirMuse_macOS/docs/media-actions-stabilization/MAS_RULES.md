# 产品规则及操作语义

## 资源矩阵
| 资源 | 播放 | 资料库 | 收藏 | 内部导航 |
|---|---|---|---|---|
| 单曲 | 仅播放、立即插播、加入队首、加入队尾 | 添加/移除 | 收藏/取消 | 专辑、歌手、歌曲电台 |
| 专辑 | 播放、随机、插播、队首、队尾 | 添加/移除 | 收藏/取消 | 专辑、歌手 |
| 平台歌单 | 同专辑 | 已验证订阅关系的添加/移除 | 收藏/取消 | 歌单 |
| 自建/协作/未知归属歌单 | 同专辑 | 禁止容器写 | 禁止容器写 | 查看歌单 |
| 艺人 | 播放/随机/插播热门歌曲，热门歌曲加入队首/队尾 | 无 | 收藏/取消 | 艺人、艺人电台 |
| 电台 | 收听 | 无 | 无 | 真有详情才显示 |
| 待播条目 | 立即播放、移到队首/队尾、从队列移除 | 单曲级 | 单曲级 | 来源、专辑、歌手，去重 |

所有能力以真实 Provider 和当前账户/队列状态为条件；未知不是 false，真正查询时才显示查询中。无支持则不展示；临时阻塞提供清楚原因。个人歌单中的曲目可独立收藏与入库，资料库删除须确保不会违反歌单只读边界。删除不与队列移除混用，平台写入不主动改变播放。多选只在真实选择能力存在时提供；默认多选队列仅移动/移除，立即播放明确针对点击条目，不宣称批量播放；不新增批量平台写操作。

## 五种意图（已有 enum，保持）
初始 A 播放、B C D 待播；选择完整 X Y Z 集合：
| 意图 | 确认后当前 | 待播 | 模式 |
|---|---|---|---|
| replaceAndPlay | X | Y Z | 显式顺序操作关闭随机 |
| shuffleAndPlay | 随机首曲 | 其余全量随机顺序 | 开启随机 |
| interruptAndPlay | X | Y Z B C D | 保留模式，批次不乱 |
| prepend | A | X Y Z B C D | 保留模式 |
| append | A | B C D X Y Z | 保留模式 |

显式插播在确认后才将 A 写入真实历史，不自动恢复 A 中断进度；失败不伪造历史或消费未确认条目。无当前时 prepend/append 仅暂存；用户点击播放后开始。已有队列双击/立即播放选择该 UUID，其他待播保持相对顺序。集合行点击从该行开始播放整个集合的后续部分，右键仅播放单曲替换队列；重复歌曲按 occurrence/UUID 确定，不用 firstIndex(trackID)。明确的顺序集合入口是否原先继承随机需核查，统一为本期显式顺序语义并回归。循环状态不因追加/插播被重置；单曲循环只影响自然结束；完整随机只在集合已知完整时生成。随机模式下显式批次内部不打散，重新主动开启随机/下一轮循环遵循已有规则并测试。

## 分页和目标绑定
页面菜单操作对象是完整 album/playlist/artistTopSongs 资源，不是已渲染的前 N 条。单曲操作才用单条。热门歌曲严格使用真实 topSongs 集合，不默默回退到艺人任意 section。缺页/重复游标/上限/网络失败均不得把部分集合标成完整；全量随机失败时保持旧播放，提示重试。顺序播放可先播首批，后续按稳定边界补齐；立即插播/队首/队尾渐进优化需具备独立批次锚点与等待边界，未满足则完整加载再原子提交。加载中显示数量/未知总数，取消无错误成功反馈。允许有意重复添加，不按 TrackID 去重合法重复出现。

所有立即改变播放的操作（含电台、艺人、普通行点击、系统入口）共同遵循最新意图。追加/插入绑定点击时的队列 ID、epoch、session，提交顺序与操作发起顺序一致；等待期间若队列被清空/替换则拒绝旧任务并反馈。若用户在新播放尚未提交时又要求添加，采用明确的当前已提交队列目标；若该队列随后失效则拒绝并提示重新添加，不把操作隐式转投新队列。此为安全默认，需保持一致。

## 电台
动态远端电台不当作普通歌曲集合，不显示无法执行的混合队列操作；直接收听会替换本地播放计划，应用实际能力及权限判断。若正在收听电台而用户要执行普通队列操作，统一确认（明确将结束电台、立即播放还是仅暂存）；取消无副作用。对 prepend/append 保留不自动播放语义；若现有引擎只支持切换并播放，必须明确提供独立确认选项，不把实际播放称为单纯追加。电台资源 ID 与当前歌曲 ID 分离，恢复、切歌及导航不得混用。

## 反馈与删除
状态结果区分 accepted/pending、confirmed、failed、unknownOutcome、superseded/cancelled。仅在确认后显示已播放/已收藏/已移除等成功信息；被取代不弹旧成功或错误。队列编辑已提交可立即反馈；失败重试、超时核对、清空撤销遵守既有契约。资料库移除确认显示资源与已知影响，禁止误删个人歌单；安全无法确认则阻塞。收藏可能由平台自动加入资料库，真实读回同步；不在客户端假设联动。
