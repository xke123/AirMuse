# 目标与完成定义

参考提交：`ccd3102a5ddaa86785a645b1e000b9afce47a38c`。本期为增量修复，不是架构重写。

## 交付目标
| ID | 目标 | 可验收结果 |
|---|---|---|
| G01 | 真实平台能力 | 歌曲、专辑、平台歌单的资料库与收藏；艺人收藏；歌曲/艺人电台。逐资源验证，未支持明确区分平台不支持与环境阻塞。 |
| G02 | 状态正确性 | 独立字段、最新意图、结果未知核对、账户隔离、缓存一致性和生命周期。 |
| G03 | 播放一致性 | 同集合不同入口等价、五种意图、完整分页、跨会话及队列隔离、真实引擎反馈。 |
| G04 | 资源身份安全 | 明确目录/资料库映射、可信所有权、导航作用域、队列条目身份。 |
| G05 | 交互可预测 | 快捷按钮、上下文菜单、艺人播放菜单、错误反馈、玻璃浮层生命周期、状态栏恢复。 |
| G06 | 轻量高效 | 无重复请求或无界辅助状态，队列和列表局部更新，资源回收，实际性能回归。 |

## 范围
保留现有全部五种队列指令、队列编辑、循环、持久化与来源数据。自建/协作/未知归属歌单容器只读，可播放或加入临时队列。资料库添加/移除、收藏/取消收藏属于正式功能，而非装饰性入口。平台歌单写入仅限经验证的订阅关系及收藏，不允许改变歌单内容。个人歌单里的单曲可独立操作，但若资料库删除会修改个人歌单成员且无法保证本期只读边界，则不开放该删除路径。内部导航保留。不做分享、外部打开、复制链接、减少推荐、歌单管理、其他音源、当前播放来源胶囊或双胶囊融合。

## 优先级
P0：阻塞核心功能的 Provider 能力、资源删除安全、状态竞态、完整集合及播放意图、假成功、空菜单误播放。P1：资源导航、菜单一致性、状态加载及同步、缓存和生命周期。P2：在正确性基础上优化顺序批次加载、玻璃视觉和反馈、性能；不阻碍独立的自动测试。

## DoD
所有可执行修复均接入生产路径，逐项复现及回归通过，原有队列/账户/恢复/窗口/歌词功能无回归。真实账户写权限与状态读回成功、原生视觉与可访问性、性能实测分别提供证据；真实平台不支持的能力保留禁用并记录证据，因账户/SDK 缺失待验证则标 PENDING_INTEGRATION 或 BLOCKED，不得宣布完整交付。所有新增设计默认值是实施建议，可基于实测调整但不能降低产品语义或安全规则。
