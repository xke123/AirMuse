# UI、反馈与性能

## 页面与菜单
专辑/平台歌单顶部：现有播放胶囊 + 资料库成员按钮 + 收藏按钮（对应真实能力启用）。自建歌单顶部仅播放菜单；艺人顶部统一热门歌曲播放菜单 + 收藏 + 电台（按能力）。歌曲右键提供单曲播放四意图、资料库、收藏、内部关系；队列右键移动不新增条目。菜单分组：播放/队列、资料库与收藏、内部导航/电台、仅队列移除。隐藏同一详情和重复目的地，合作艺人子菜单使用真实关系。没有能力不留空菜单；状态未知/处理中显示实际原因，有查询才称查询中；失败可重新核对。一级按钮 plus/checkmark 与 star/star.fill 仅以已确认状态为准，可另显示 pending，不能伪确认。现有艺人信息入口可保留，不增加无功能更多菜单。

同一个页面播放菜单与右键共享 resolver 和 selection，冻结菜单打开时的目标与上下文；点击时注册意图并再次校验可用性。页面切换/账户变化时旧菜单关闭，空描述/禁用/未准备好不触发 replaceAndPlay。保持原生 NSMenu 键盘导航及辅助功能。自定义胶囊保留现有组件，关闭/失焦/父窗口隐藏/销毁时清除本地监听、子 Panel 与 pending 回调，关闭时立刻禁止重复选中。键盘 Escape、Return、上下键、焦点恢复不吞无关窗口事件；点击外部应用、屏幕边缘、多屏、窗口移动、快速展开关闭均实测。按 NSScreen 可见空间定位；尺寸不足时采用可访问的滚动/原生菜单降级。不要为了连续形变重写整个 UI。Enhanced 真 Liquid Glass 连续几何/材质过渡须验证；Original 保留原始皮肤与清晰菜单，Reduce Motion/Transparency 正确降级；淡入仅称淡入。

## 反馈
统一现有 queueDockView 反馈接线：队列编辑成功以真实提交数为准；加载时显示数量/取消；实际播放由引擎确认，失败展示重试/跳过；旧意图过期不冒充成功。错误路由一次，不重复弹 Toast/日志 UI。资料库移除有明确确认；取消无副作用。所有入口（拖拽、菜单、键盘、队列重试、艺人）统一反馈。默认轻量 Toast 约 2–3.5 秒为调校建议，避免遮挡主要控件，VoiceOver 可读取重要结果。对高频追加合并视觉反馈（例如 150–250ms 合并窗口，可实测调整），真实操作不合并丢失。单曲一次轻微弹性，集合数量提示，不为普通播放/失败触发添加庆祝动画；仅在可见状态运行，动画/Toast 新任务取消旧视觉任务且不取消业务。

## 状态栏与窗口
`AppDelegate.activateApp` 不遍历所有非 Panel 窗口；调用既有 AppLifecycleCoordinator/UnifiedStageController 明确显示实际舞台，保持 Normal/Mini 和模块显隐，不复活账户、日志等辅助窗口，不重新创建引擎或改变播放；关闭最后窗口后可恢复，退出沿现有持久化/关闭流程。状态栏图标及菜单保留原生实现，不扩展为第二套播放器控制。

## 性能验证协议
- 记录当前基线与修复后相同环境（设备、系统、SDK、构建配置、歌曲数、账户状态）；100/1k/10k 队列规模，350+ 歌单，超过1000资源缓存，50次快速编辑，至少一次长时间空闲/重复开关菜单。记录 P50/P95、主线程耗时、API 请求数、App/WebKit 内存、活动 Task/监听/图层数量；目标不等于实测。
- 纯菜单解析不触发网络，打开菜单不逐项请求；必要首次状态查询按需去重，复用页面响应。资源变化按 key 局部更新，不因音频进度重绘菜单/列表。队列顺序变化使用现有差量更新，验证拖拽、滚动、选中项；不重复图片解码/请求。
- 60Hz/120Hz 整帧预算 16.67/8.33ms；响应争取一帧内，昂贵操作后台/异步完成。空闲装饰时钟为零，隐藏后无持续 UI 刷新或悬挂 Panel/监听；缓存及辅助记录有界。测试活动任务高水位及完成后回落，不将瞬时峰值冒充泄漏。性能退化须解释、优化及记录，不能凭代码行数宣称提速。
