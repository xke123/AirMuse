# 产品语义与菜单矩阵
AirMuse 是多音源播放器，不是完整 Apple Music 管理客户端。资料库成员管理和收藏是高频正式目标；个人歌单容器只读。以下为目标矩阵，非 Apple Web 实测菜单清单。

| 资源 | 播放动作 | 资料库 | 收藏 | 导航及其他 |
|---|---|---|---|---|
| 单曲 | 仅播放此歌曲、立即插播、加入队列开头/末尾 | 添加/移除 | 收藏/取消 | 歌曲电台、查看专辑/歌手 |
| 专辑 | 播放、随机播放、插播、队首/队尾 | 添加/移除 | 收藏/取消 | 查看专辑/歌手 |
| 平台歌单 | 同专辑 | 添加/移除（仅已验证的订阅关系） | 收藏/取消 | 查看歌单 |
| 自建/协作或归属不明歌单 | 同专辑 | 禁止 | 禁止容器写入 | 查看歌单 |
| 艺人 | 播放/随机/插播热门歌曲、热门歌曲加入队首/队尾 | 不提供 | 收藏/取消 | 艺人电台、查看歌手 |
| 电台 | 收听 | 不提供 | 本期不提供 | 有真实详情时查看电台信息 |
| 待播条目 | 立即播放、移动队首/队尾、移除 | 单曲添加/移除 | 单曲收藏/取消 | 可用时前往来源、查看专辑/歌手 |

仅显示能力已实现且有效的动作；短暂状态未知可以禁用并显示查询中，不把未知当否。已位于同一资源详情隐藏重复导航，按真实资源 ID 比较而非只按类型；合作艺人可选子菜单。个人歌单中的歌曲仍可独立收藏或操作资料库，但绝不修改歌单成员；若平台操作会连带删除个人歌单内容且无法接受或确认影响，不开放该路径。禁止创建、编辑、删除任何歌单，禁止添加/移除/重排歌单成员，禁止分享、复制链接、外部打开、减少推荐。队列移除不等于资料库删除。

## 五种意图
初始当前 A，待播 B,C,D，新集合 X,Y,Z：
| 意图 | 确认后的当前 | 待播 |
|---|---|---|
| replaceAndPlay | X | Y,Z |
| shuffleAndPlay | 随机首曲 | 其余完整随机顺序 |
| interruptAndPlay | X | Y,Z,B,C,D |
| prepend | A | X,Y,Z,B,C,D |
| append | A | B,C,D,X,Y,Z |
顺序播放明确关闭随机；随机播放完整集合洗牌一次，首曲也随机；其余三种保留模式，不打散明确安排的批次。循环设置保留，但单曲循环只影响自然结束。插播不恢复 A 的中断进度，成功后 A 进入实际历史；失败保留未消费条目与可重试目标，按真实引擎状态展示。重复歌曲允许独立 UUID；移动不重新创建条目。下一首播放与加入队首同义，不重复菜单。无当前会话时 prepend/append 仅建立待播计划，不自动播放。动态电台不接受普通队列混合；确认结束电台时准确表述是否立即播放或仅建立待播计划，取消无副作用。

点击详情中的歌曲：从该行开始播放所在集合，保留该集合真实来源；右键仅播放此歌曲：单条替换；队列双击：消费指定条目并保留其他待播顺序。多选时使用选择集合并保留页面顺序，明确动作适用数量；无批量平台写能力不提供批量写。歌曲行重复出现时用行/队列身份，不用首个 TrackID 匹配。

## 操作反馈
成功依据真实提交结果，失败可见且可重试；批量加载显示进度，取消明确，防止重复误触但允许用户有意重复添加。删除资料库与取消收藏分别操作，不能隐式清除对方状态；服务端联动后同步。任何平台写操作不主动修改播放队列、历史、来源或音频；删除后若资源不可用，按已知目录 ID 正常解析播放或报告失败。资料库移除确认显示资源名称与已知影响，不宣称仅移除本地缓存。若可能删除自建歌单容器则禁止。

## 与现有队列契约的衔接
五种产品意图不意味着新增五套业务接口。现有 QueueInsertionIntent 四种直接使用 submitIntent；仅新增原子随机替换能力。明确顺序播放关闭随机属于本期页面菜单契约；其他旧入口保持兼容直至完成回归。提交成功与音频确认分开呈现。
