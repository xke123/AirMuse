# UI 与交互规范
不改变现有音乐库整体布局、外框、皮肤及单队列按钮。专辑与平台歌单详情页顶部：播放胶囊（含下箭头）、资料库 plus/checkmark、收藏 star/star.fill。个人歌单只有播放胶囊；艺人页热门歌曲播放胶囊、收藏、支持时电台；电台页收听及可用信息。不要额外通用更多按钮承载空菜单。歌曲行现有快捷播放保持，右键/··· 同一动作描述；允许现有布局内提供 hover 更多按钮，键盘也能到达。资料库已添加状态点击触发明确移除确认，而非无提示删除；收藏可直接切换并显示 pending；未知状态不得显示假 plus/空星。状态颜色不作为唯一提示，tooltip 与 accessibilityLabel/Value 随状态变化。

播放胶囊点击展开五项：播放、随机播放、分隔线、立即插播、加入队列开头、加入队列末尾。单曲不显示随机。艺人菜单明确限定热门歌曲；电台仅收听，不做无意义五项。保持锚点连续形变，优先 NSGlassEffectView 和现有动画机制，SDK 实证选择适用容器；Original 模式使用原皮肤兼容表现，Enhanced 原生材质，减弱透明度有清晰背景，Reduce Motion 即时切换。展开/关闭可中断，旧完成回调不得修改新状态；点击外部、Escape、再次点击关闭，关闭后焦点归还锚点。窗口边界内布局，长标题截断/tooltip，键盘方向键/Enter，VoiceOver 可读。无双胶囊融合任务。

普通右键使用 NSMenu，按 SPEC 顺序分组：播放 → 资料库/收藏 → 导航/电台；队列移除放末尾。隐藏空组及多余分隔线；同一资源当前页导航去重。队列右键使用移动而不是加入，按条目 ID；操作过期给出反馈，不吞错误。自建歌单中曲目可有单曲操作，但不得出现编辑歌单/从歌单移除。平台能力未验证不显示可执行项。

成功/失败/加载采用现有轻量反馈组件（必要时局部扩展），不遮挡播放器、无需额外窗口，不虚假成功。删除确认采用原生 NSAlert 或已有安全确认机制。打开菜单不发送播放/写请求；关闭无业务副作用。UI 真实响应来自共享状态与队列快照；进度更新不刷新菜单和列表。验收需录制实际双模式画面及键盘流程，原生玻璃视觉未实测不标完成。

## 已有 UI 接线
迁移 LibraryContentView 的 LibraryQueueAction / makeQueueContextMenu、现有艺人收藏按钮、艺人电台入口及队列 NSMenuDelegate 到统一描述。复用现有反馈，不新增平行 Toast 系统；原艺人收藏错误仅日志的行为必须替换为可见失败反馈及安全状态核对。
