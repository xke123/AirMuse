# AirMuse 搜索栏重构 — 目标与交互规范

## 1. 重构目标

将当前仅支持“扁平混排 30 条结果”的最小搜索，升级为贴合 Apple Music 网页版全量能力的原生 macOS 搜索体验，同时保持 `AirMuse_macOS` 歌曲库面板（`330 × 390` @1× / `495 × 585` @1.5×）的紧凑尺寸、Original/Enhanced 双模式与 Liquid Glass 质感。

核心目标：
1. **搜索空态体验完整**：点击搜索按钮立即聚焦输入框，提供「最近 5 条搜索历史（Liquid Glass Expand 浮层）」与「3 栏类别浏览」。
2. **范围切换清晰**：搜索栏右侧提供原生胶囊/开关切换「Apple Music 搜索」与「资料库搜索」，默认选中 **Apple Music 搜索**。
3. **搜索结果页原版双栏 + 动态分类**：恢复歌曲库原版双栏布局（左 `126pt` 分类栏 + 右内容区），左侧分类**不写死**，按当前关键词实际返回的非空分类与顺序动态生成，默认首项选中 **最佳结果（Top Results）**。
4. **25 条标准分页**：统一 `limit = 25`，基于 AMP API 返回的 `next` 游标实现滚动加载下一页。
5. **预留完整艺人主页接口**：搜索结果中的艺人点击走统一路由，方便后续直接替换为完整艺人主页。

---

## 2. 交互与界面规范

### 2.1 入口与焦点行为
- 点击 `LibraryTopBarView` 右侧搜索按钮（🔍）或触发快捷键（`⌘F`）进入搜索模式。
- 宿主窗口（`PlayerWindow`）确保成为 key window 后，立即调用 `makeFirstResponder(searchField)`，**光标自动落入搜索输入框**。
- 搜索栏右侧放置范围开关：`[Apple Music | 资料库]`（索引 `0 = Apple Music`，`1 = 资料库`），默认选中 `0`（Apple Music）。
- 切换范围开关时：
  - 若当前输入框非空：立即以新范围重新发起搜索（递增 `searchGeneration`）。
  - 若当前输入框为空：保持空态（历史浮层 + 3 栏类别浏览）。
- 按 `Esc` 或点击返回按钮：若关键词非空可先清空回到空态，再次按 `Esc` 或点击返回按钮退出搜索模式并恢复主导航栏。

### 2.2 搜索空态（未输入关键词）
- **布局**：隐藏左侧 `sidebar`，右侧 `contentView` 占满全宽。
- **输入框下方：Liquid Glass Expand 搜索历史浮层**
  - 使用 `NSGlassEffectContainerView` + `NSGlassEffectView` 实现从顶部搜索胶囊下方展开的悬浮玻璃面板（Reduced Transparency 下自动回退为高对比度半透明深色面板）。
  - 最多展示最近 **5 条**搜索历史（本地 `UserDefaults` 持久化）。
  - 交互要求：
    - 点击某条历史记录 → 填入 `searchField`、收起浮层并立即发起搜索。
    - 每条历史右侧提供**单条删除按钮（`×`）**，删除后立即刷新列表（删至 0 条时自动收起浮层）。
    - 浮层提供**「全部清除」**按钮，一键清空所有历史并收起浮层。
  - 当用户输入非空关键词或提交搜索时，历史浮层自动收起；清空输入框回到空态且存在历史记录时可重新展开。
- **下方内容区：3 栏「类别浏览」**
  - 在 `LibraryContentView` 支持 **3 栏网格模式**，展示固定的类别浏览卡片（对接 AMP 浏览分组或缓存的流派/心情分类）。
  - 点击任意类别卡片 → 钻取该类别对应的精选歌单/专辑/曲目内容页。

### 2.3 搜索结果页（有关键词）
- **布局**：恢复歌曲库原版**双栏布局**（左侧 `sidebar` 宽 `126pt` + 右侧 `contentView`）。
- **左侧边栏：动态分类列表（禁止写死）**
  - 目录搜索请求 `/v1/catalog/{storefront}/search` 时携带 `&with=topResults` 及完整类型（如 `songs,albums,artists,playlists,stations` 等），`limit = 25`。
  - 根据当次响应中的 `meta.results.order`（以及实际非空的 `results` 分组）动态生成左侧分类条目；资料库搜索 `/v1/me/library/search` 按实际非空的 `library-*` 分组顺序动态生成。
  - **第一项默认选中「最佳结果」**（若接口未返回 `top` 分组，则回退选中第一个非空分类）。
  - 点击左侧栏不同分类 → 右侧 `contentView` 立即切换显示该分类下的结果（无需重复请求首页数据）。
- **右侧内容区：结果呈现与 25 条分页**
  - 展示当前左侧选中分类的具体结果（单曲、专辑、艺人、歌单、电台等）。
  - 保存每个分类在 AMP 响应中自带的 `next` 分页链接；右侧栏滚动到底部且当前分类 `next != nil` 时，自动请求下一页（`limit = 25`）并追加到列表末尾。

### 2.4 艺人主页预留
- 搜索结果（含「最佳结果」与「艺人」分类）中的艺人条目点击时，统一通过 `onArtistSelected(artistID:isLibrary:)` / `.artist` 路由分发；当前保留现有临时详情过渡，待完整艺人主页完成后直接替换路由目标即可。
