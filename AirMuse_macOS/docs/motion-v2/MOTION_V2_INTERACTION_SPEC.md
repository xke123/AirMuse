# AirMuse Motion V2 — 交互效果实施契约

所有时长与阈值均为初始建议，允许基于录屏和实测调整，必须记录决策。每个ID是独立验收项。统一规则：立即响应用户意图，动画不延迟业务；每个过渡捕获generation，旧回调不得提交；最终模型几何、命中、可访问性同步；Original/Enhanced均可操作；减少动态效果时取消非必要位移和扫光，减少透明度时使用高对比不透明替代。以下每项的降级均叠加这些全局规则。

## M01 — 启动卷轴
- 目标：非阻塞卷轴。
- 起始/结束：以当前可见呈现状态为起点，非阻塞卷轴为目标状态；提交后无遗留过渡对象。
- 触发、关键帧及参数：首次展示即交互；0–550ms玻璃上下帽分离，内容后段渐入。
- 中断与竞态：任何操作立即结束装饰过渡。
- 降级：直接显示。
- 验收：首屏不等待；点击一次即可操作。
- 证据：录屏或截图、确定性状态测试、性能采样；真实环境未运行标记 PENDING_INTEGRATION。

## M02 — Normal/Mini 水晶形变

- 触发、关键帧及参数：双击空白或按钮；0–320ms高度连续变化，内容裁切，末段mini淡入。

- 降级：立即布局。
- 验收：10次快速反向无跳帧/错误命中；音频不重载。
