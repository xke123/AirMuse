# PO — 目标、范围及完成定义

## 产品主线
音乐库 → 选中资源 → 入队或开始电台 → 当前播放 → 返回真实来源 → 继续浏览。来源是可解释、可导航的播放上下文，而不是歌曲属性或当前页面名称。

| ID | 目标 | 验收 |
|---|---|---|
| G01 | 真实来源 | 同曲不同队列条目、分页、历史、循环和恢复保持来源正确 |
| G02 | 当前播放投影 | 主播放器与来源身份一致，准备/失败/暂停/恢复不冒充播放 |
| G03 | 电台独立会话 | 电台 ID 与种子及实际曲目分离，动态切歌、能力、直播和未知状态正确 |
| G04 | 队列自适应及切换 | 本地只显示真实待播；远端未知不显示 0；明确确认、原子暂存、无残余 |
| G05 | 纯内部导航 | 来源/专辑/歌手正确去重，安全定位、返回、失效降级且不打断音频 |
| G06 | 双控件与效率 | 复用现有底条、玻璃容器及过渡；独立命中、互斥展开、零空闲装饰时钟 |

## 范围
音乐库底部右侧来源胶囊和现有播放列表按钮；来源菜单、队列来源右键入口、真实资源导航；电台普通/直播/未知能力及面板；必要的协调器、引擎事件、来源捕获、快照迁移和测试修复。主播放器与 Mini、快捷键只作所需能力和状态一致性接线，不重新设计外观。

排除：第二播放器/队列、隐藏旧队列恢复栈、自动恢复电台前的普通队列、新推荐引擎、生成/猜测远端曲目、远端队列写入、歌单编辑/创建/删除、分享/复制链接/外部打开、新音源、无关 UI 改造。既有资料库与收藏高频功能保留，不借此扩大权限。

## 决策记录
已沿用用户约定：来源定义、原底条保留、左右双胶囊、来源菜单三类内部导航、普通待播列表 50% 宽/70% 高、自建歌单只读。方案默认：电台右侧入口保留并切换电台面板（而非隐藏），电台→队首/队尾确认后暂存不自动播放，普通→电台不隐藏保存旧队列；搜索/分类精准跳转、曲目定位、有界加载、互斥展开为本次规划建议，按此次采用方案实施。具体尺寸/时间为初始参数；不以实机未验证的能力作为承诺。若遇真实平台限制，记录阻塞与最小降级，不能悄悄改变契约。

## 交付门槛
G01–G06 均有生产调用链和对应测试；没有真实可访问目标时隐藏动作并说明降级；电台能力未验证时限制操作。保留现有功能、测试和可构建性。真实账户、直播、电台恢复、原生材质及性能需实机证据，未验证单独列出。
