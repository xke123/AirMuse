# PO — UI、交互、原生材质及性能

## 视觉约束
保留原始底部玻璃条及经典水晶外框，右侧两个相邻浮动胶囊。来源在左、队列入口在右；独立点击/焦点/VoiceOver。复用 `LiquidFusionQueueDockView` 宿主及 `NSGlassEffectContainerView`，两个真实 glass surface 为同级，验证 SDK 实际融合能力，不用普通背景模糊、截图或单个绘制背景冒充融合。Original 模式使用原有皮肤及适配形态；Enhanced 使用公开原生材质，Reduce Transparency 使用清晰非透明降级。不要整体换肤。

| 参数 | 初始值（按实际布局调校） |
|---|---|
| 收起高度 | 24pt，复用现有按钮 |
| 来源宽度 | 内容自适应，上限约 180pt |
| 间距/右边距 | 3–6pt / 10pt |
| 普通面板 | 音乐库窗口宽 50%、高 70%，按可用区域夹紧（现代码 65% 高） |
| 电台面板 | 内容自适应，不制造巨大空白；不超出可用区域 |
| 文字/图标过渡 | 180–220ms |
| 展开/收起 | 280–340ms，复用 MotionTokens |

窄窗口先缩来源文本再降为类型图标；Tooltip/AX 始终提供完整名称；优先保留队列入口。无 current 隐藏来源（staged 队列不显示队首为当前）；未知来源可显示名称并提供真实歌曲关联导航；无任何动作则不可点击。普通队列显示真实待播数量，未完成分页标记加载/部分状态；remote 未知数量绝不显示 0。直播与算法电台用实际能力和状态呈现，不伪造节目。

## 展开行为
统一 dock interaction state：collapsed / originOpen / queueOpen（queue 内容 local/remote）；最新用户意图优先。点击另一个控件关闭旧面板并展开新面板，另一入口一直可用、不被遮挡。按真实 presentation geometry 反向，取消旧 completion，保持 hit test、AX、焦点与可见几何一致；打开期间模式改变按新快照切换面板/关闭过期菜单；关闭不触发播放。ESC、外部点击、失焦、隐藏、窗口销毁、账户切换安全清理。只在可见状态运行有限动画。菜单使用真实可用导航项；无有效项不执行任何播放兜底。已有 NSMenu/原生玻璃浮层组件优先复用。多艺人子菜单保持键盘与 VoiceOver 可操作。

## 普通面板与电台面板
普通面板维持现有 toolbar（左清空/撤销按能力，右随机/单曲循环/列表循环、关闭），只列 upcoming，支持原有排序、删除及菜单；当前歌曲不重复加入待播。保留加载、失败、重试、空状态。电台面板显示电台名、真实状态、当前实际歌曲/节目、可用 transport 控制、后续由电台决定的说明。连接/失败/暂停优先于“续播中”，不展示禁用的整套普通编辑控件。重试是重试实际 station，不调用普通分页重试。所有图标与控制均有 AX label/value；支持键盘、焦点恢复、Reduce Motion/Transparency。

## 局部更新与性能
- 使用低频语义快照；进度/音量/歌词不刷新来源；相同 station 内切歌只更新歌曲关系与必要内容，不闪烁来源，不触发来源过渡。
- 现有列表差量更新按 UUID；同 ID 元数据变化更新实际行，远端同 UUID 新 item 不可遗漏。无需在打开菜单时逐曲目请求。关系请求仅在必要时发起，去重、取消、校验身份；导航定位额外分页默认最多 3 页。
- 不因显示/导航/动画创建额外 WebKit、不改变音频生命周期、不做全页高频 redraw。零空闲装饰时钟；反馈/图层有界，隐藏后释放；UI 操作不阻塞主线程。
- 在相同设备、构建配置、窗口尺寸、屏幕刷新率记录基线和修复后 CPU/GPU/能耗、主进程与 WebKit 内存、主线程 P50/P95、动画帧耗时及请求数量；60Hz 16.67ms/120Hz 8.33ms 为整帧预算目标，不宣称实测。100/1000/10000 待播、连续切歌、快速反向、长时电台空闲及滚动场景；Instruments 证据与原生截图/录制分开记载。不得用初始化测试宣称实际光学融合。
