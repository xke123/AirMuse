# PO — 精确产品契约

## R1 来源身份
来源是用户选择并添加此条目的真实上下文。专辑/歌单/艺人集合动作从该资源捕获来源；详情页行点击、行右键、搜索、收藏/资料库分类、榜单、推荐/浏览按实际页面捕获。选择集合不是歌曲的 album 属性；点击卡片中真正选择的资源而非当时的其他页面。捕获发生在用户动作时，异步分页、插入、播放提交及历史重用不得重新读取 currentDetailOrigin 或 activeTabIndex。真实未知用 unknown；禁止猜测。新入队生成 UUID，同曲多次可不同来源；移动、循环、上一首、已有条目立即播放保留原 identity 与 origin。清空待播不修改当前来源；分页批次内来源一致。

| kind/上下文 | 显示 | 目标 |
|---|---|---|
| album | 专辑名 | 真实目录或资料库专辑 |
| playlist | 歌单名 | 真实歌单，只读个人容器 |
| artist | 艺人名 | 对应艺人热门歌曲区 |
| station | 电台名 | 可访问电台详情或已知广播栏目/种子页面 |
| library | 具体分类名 | 收藏歌曲、全部歌曲等真实分类 |
| search | 搜索结果或搜索词 | 原 query + scope + 真实分类（若已保存） |
| chart | 榜单名 | 已知榜单资源/栏目 |
| forYou/browse | 推荐/浏览栏目名 | 已知稳定栏目 ID |
| song | 单曲 | 有独立内部页面才允许 |
| unknown | 未知来源 | 无 |

## R2 当前来源显示
confirmedCurrent 是来源权威，但需要与同版本 transport / 当前展示曲目一致。replace 可能清除旧 confirmed；没有 confirmed 不凭空制造旧状态。可选择显示“正在准备 X”及明确 pending 标记，或暂不显示来源；不得用 pending 冒充正在播放。暂停/停止/耗尽若 UI 保留已确认歌曲则保留来源并标实际状态；stage-only 无 current，隐藏来源，显示待播队列。播放失败保留可证实上下文与失败提示，不宣称仍播放旧歌。账户退出/换会话清除旧可操作来源。首次恢复不自动播放。

## R3 导航契约
来源胶囊只展示内部导航：前往来源、查看专辑、查看歌手；电台按真实身份增加种子导航，见 RADIO。只有已知可访问类型化目标才显示。源与专辑/艺人同身份时去重；目录和资料库别名只有确认映射才视为同一资源。多个合作艺人使用子菜单并去重。当前页面正是目标时不重建，允许定位动作保留一个入口；没有定位意义才隐藏重复项。

- 点击导航冻结目标与当前实际歌曲；若菜单期间切歌，关闭过期菜单或重新解析，不把点击重定向到新歌。导航前验证账户/资源权限。
- 纯内部 route API，不调用可能触发播放的 handleItemClicked(song/radio)。不发播放/暂停/seek/skip/queue write 或平台 mutation 指令，不重建引擎。
- 页面加载成功再定位，使用实际 occurrence identity（存在则用）；其次唯一可信目录/资料库匹配；重复条目无法消歧时不假称精确定位。高亮非选择播放；源页不存在则保留当前页面并提示。若歌已移除，只有确认完整列表后才说“不在列表”；未完整加载显示“尚未定位”。使用有界分页与取消，默认最多 3 页额外定位查询（建议可调），不下载整个大型集合。已有目标页优先使用缓存，返回路径及滚动位置正常。
- 访问失败/下架/权限不足不改变历史来源名；网络失败可重试导航，不自动跳转其他内容；无内部页面不打开外部 URL。

## R4 现有操作保持不变
五种普通意图继续复用 submitIntent：replace/shuffle 替换，interrupt 保留原待播且立即播放，prepend/append 不影响当前播放，空闲可暂存；整集合按既有分页契约，不能把已渲染数组当全量。来源功能不得重新洗牌、重建队列或触发额外播放。已有队列条目移动/删除按 UUID；来源跳转与队列右键共享纯导航。资料库/收藏、个人歌单只读规则不变。电台特例以 PO_RADIO 为准。
