# 验收与故障注入

使用现有测试框架、可控 mock engine/transport、测试时钟、确定随机种子。测试通过显式 continuation/barrier 排定事件顺序，不靠随机 sleep。测试 mock 不进入生产。

| ID | 场景与预期 |
|---|---|
| T01 | A 当前，B/C/D 待播：自然结束消费 B，UI 显示 C/D |
| T02 | 同曲两条不同来源：删除第二条不影响第一条，播放来源按 entryID |
| T03 | 随机一轮所有待播 ID 恰消费一次；耗尽停止；开启/关闭不重播已消费项 |
| T04 | 随机状态拖拽、插入、追加；关闭随机仍尊重显式编辑 |
| T05 | one 自然结束重播当前，手动 Next 消费首项；one/all 互斥 |
| T06 | all 完成后有效成员重新生成，删除条目不复活；随机跨轮正确 |
| T07 | A 播放时清空，当前位置及音频不变，all 不复活；one 保留 |
| T08 | A 当前、B/C/D/E 待播，双击 D，确认后 B/C/E 仍待播 |
| T09 | 拖动 B 时 A 结束选中 B，旧拖拽拒绝，不移动当前或误移动 C |
| T10 | 批量插入 X/Y/Z 保持顺序，append 保持已有待播；空闲不自动播放 |
| T11 | 随机/跳播后 Previous 返回实际历史；3 秒阈值及多次回退/前进 |
| T12 | 旧结束事件、重复结束、旧 engine/session、同 TrackID 不同 entry 均不误推进 |
| T13 | 播放失败、快速 A→B→C、暂停准备、停止与编辑并发，不发布虚假确认状态 |
| T14 | 350 首歌单分页完整，重复歌曲保留；页重复/游标循环有界失败 |
| T15 | 分页过程中清空、切换队列、退出账户，旧结果不得提交；追加尾部顺序不乱 |
| T16 | 部分加载失败有真实状态和重试，不展示虚假总数；完整随机等待集合 |
| T17 | 本地/远端切换，电台来源继承，无可编辑队列时禁用；取消切换不打断 |
| T18 | A→B、注销、旧快照和迟到保存：私人数据不泄露 |
| T19 | 重启暂停恢复原随机顺序、条目 ID、来源、位置；旧 schema 迁移、损坏文件安全处理 |
| T20 | 进度/歌词/音量变化不重绘队列；结构流初始值、取消及旧 revision 防护 |
| T21 | UI 首行固定，50%×70% 尺寸、开合/反转、外部点击、键盘及焦点恢复 |
| T22 | 多选/拖拽/右键/清空反馈、未知能力禁用，真实快照与实际下一首一致 |
| T23 | 反复打开关闭浮层不增加常驻监听/玻璃实例，不产生播放或网络请求 |
| T24 | 撤销仅在同一会话和安全 revision 生效，不能覆盖后续编辑或启动播放 |

性能预算（目标非实测）：点击视觉反馈一帧内；60Hz 16.7ms / 120Hz 8.3ms 帧预算；队列结构发布不受进度频率影响；100/1000/10000 条目测试操作延迟、滚动掉帧、内存与快照写入成本，记录机器、系统、构建配置、P50/P95。不得承诺外部网络延迟或无缝播放。真实 Apple Music 账户验证连续切歌、远端电台、失败恢复；用 Instruments/系统工具记录 App 与 WebKit 子进程资源。无法执行的测试明确 PENDING，不以单元测试冒充实机验收。
