# Liquid Fusion Dock 队列 UI

## 布局
保持现有音乐库皮肤与底部水晶条。右下角浮动来源胶囊 + 队列圆按钮，独立命中区域，复用同一玻璃融合容器。来源功能由独立任务实现，本次只接入其真实状态及共享材质，不重复改造。底部距边 6–8pt、轻叠玻璃条 2–4pt、按钮高度 24–28pt、间距 3–5pt 为初始调校值。

队列展开宽 = 音乐库面板宽 × 0.5，高 = 面板高 × 0.7，右下锚点向上向左扩展，覆盖内容但不改变原浏览滚动或窗口大小；狭窄窗口确保工具栏可用并记录最小尺寸降级。首行固定工具栏：左清空（trash，tooltip），右随机 shuffle、单曲 repeat.1、列表 repeat；无大标题、无当前歌曲重复展示。下方仅待播列表纵向滚动；标题/数量可用轻量行，未知数量不猜测。每行封面、歌曲、艺人、可选右键入口；长文本截断并 tooltip。空队列、部分加载、错误重试、远端不支持状态明确可区分。加载期间不阻断已知列表操作。

## 交互
单击选中、双击播放、Cmd/Shift 多选、Delete 删除、Esc 收起；拖拽实时插入指示，提交使用 ID。右键：播放、移到下一首、移到末尾、移除、前往来源、查看专辑、查看歌手（仅真实可跳转能力）。音乐库所有歌曲入口新增立即播放/下一首播放/添加到队列；专辑歌单支持整批加入。操作成功由真实快照驱动，失败显示轻量反馈。清空可通过短时撤销或明确确认防误触；不停止当前歌曲、不改远端收藏。模式选中状态具有非颜色提示；不支持操作禁用并说明。

## 原生实现
AppKit 优先；macOS 26+ NSGlassEffectContainerView + NSGlassEffectView（contentView、regular 材质用于密集文字，clear 用于简洁控件），实际 SDK 校验属性与可用性；NSTableView + NSScrollView + AppKit 拖拽；SF Symbols。使用现有通用形变调度；同一玻璃对象从按钮几何展开，分离后向上扩展，关闭收缩再融合。初始展开 360ms、收起 280–320ms、内容渐显 120–160ms；可中断、反转、从 presentation geometry 接续。不能只缩放文字/封面，不能用普通 blur 冒充原生材质。旧系统使用现有皮肤兼容路径并明确标记；Reduce Motion 简化、Reduce Transparency 保证可读性。

浮层命中区域与实际可见几何同步；点击外部或 Esc 关闭、来源菜单互斥、窗口隐藏时取消动画及监听；关闭后焦点返回队列按钮。浮层开合不得调用播放/网络、重建 WebKit 或改变当前页面。打开面板即收到真实快照；列表按稳定 ID 更新并保留滚动、选中、焦点。封面异步按条目校验，复用图片缓存。大列表复用行、仅可见项加载。原生玻璃效果与自定义透明窗口实机验证后再标完成。
