# PD — 测试与验收

所有 R/E 初始 TODO；用确定性 actor gate / continuation / fake clock 控制时序，不靠 sleep 碰概率。Fixture 只在测试或独立验证宿主，提供两种 provider、碰撞 ID、非 URL cursor、独立账户、不同 capabilities 与可阻塞引擎。音频探针共享计数，故意注入 stop failure、迟到事件、准备失败；不把它当真实音频证据。测试必须穿过真实 Application/Coordinator/Router/Store，UI 测试通过通用入口执行，而不是只验证协议初始化。保留既有测试。
