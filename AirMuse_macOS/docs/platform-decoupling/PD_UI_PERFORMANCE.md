# PD — 通用前端、视觉及性能验收

## UI 输入
通用 UI 只认识 BrowsePage/Section/ResourceIdentity、状态快照及 action descriptors。页面由 AirMuse 现有 renderer 决定：专辑/歌单/艺人/电台卡片、歌曲行、搜索、资料库、详情头部。平台提供真实栏目和数据，不提供任意布局脚本。稳定 route ID 映射 Tab/Sidebar；账户和平台入口仅做必要的选择与管理，不重做视觉。已注册但未激活/未授权/不支持/加载失败/真实空列表清晰区分。实际生产仅 Apple Music 可用时保持现有默认布局与入口，不伪造其他平台可用能力；测试 Host 可展示 Fixture 平台。

浏览平台与播放平台独立标识。切换浏览保持原播放音频、队列、进度、歌词和来源；收藏根据目标资源所属平台，不因当前页错误路由。来源跳转通过 NavigationService 改浏览上下文，切换平台后再打开明确 route；无访问权/未知目标提示，不用默认 Apple Music 或同名栏目兜底。已有详情只按完整身份去重；定位歌曲优先已加载数据，有界分页（现有 3 页策略可复用），找不到不伪造位置、不触发播放。

## 视觉不变量
原始水晶外框、原底条、Normal/Mini、歌词、UnifiedStageController 单宿主、Original/Enhanced 保持。Enhanced 使用公开 AppKit 原生 Liquid Glass；Original 保留原皮肤。双玻璃 Dock、来源菜单和普通/远端面板互斥展开及命中；远端未知列表不显示 0 或假条目，隐藏无效编辑工具栏，控制由能力决定。当前歌曲、来源、transport 和队列 owner 必须是同一权威快照或一致版本投影。来源显示签名含 provider/scope/resource 及必要动态 item 身份；同一来源无需重复动画；快速切换 token 化取消，旧完成回调不能覆盖文字、图标或 hit region。页面切换、失焦、窗口隐藏、销毁清理菜单、事件监听和关系查询；键盘/VoiceOver/Reduce Motion/Transparency、缩放、窄窗、多屏不退化。

## 性能与测量
不得引入新的常驻 WebKit、Web Runtime、轮询、全量重绘、重复订阅或同步 I/O。只浏览的平台不创建引擎，未激活平台不创建会话和网络连接；实际音频宿主独立于可视窗口生命周期。平台抽象是轻量值类型/协议，不引入动态插件运行时、额外 SDK 或非必要依赖。进度、音量、歌词高频事件不得触发列表/来源重建；队列按稳定 UUID 差量更新。图片解码/数据解析 off MainActor，命令/UI 发布尽量低频，有界任务及缓存。所有任务按 owner 生命周期取消、清理，避免 retain cycle。

PD00 与 PD09 同一设备、系统、SDK、配置、数据集和测试步骤对比：
| 指标 | 建议验收 |
|---|---|
| 冷启动到可交互 | 10 次冷启动，报告 p50/p95 与波动；目标 p95 不退化超过 10%（环境波动需解释） |
| 空闲 CPU / RSS / GPU / 能耗 | 无音源、已登录空闲、播放中分别采样；同配置目标无可重复显著退化，RSS p95 建议不增逾 10% |
| WebKit/引擎实例 | 未激活 0；仅浏览 0 播放引擎；单活动音频权；切换/注销后无孤立宿主 |
| 100/1000/10000 队列 | 追加、排序、快照、滚动、保存，对比 p50/p95；不因平台层全量复制或排序 |
| 帧耗时 | 60/120Hz 整帧预算 16.67/8.33ms 目标，记录实际分布及卡顿；不虚构达标 |
| 切换 50 次 | 记录任务/监听/引擎/内存数量是否稳定，旧任务不残留，真实音频单所有者 |
| 网络 | 无多余平台初始化、无菜单 N+1、无每 tick 请求；分页及状态请求次数对比 |

上述 10% 是本期建议的回归门槛，不是已测数据；不能以百分比掩盖音频错误、隐私泄漏、无界增长或启动失败。实机无法运行时记录 PENDING_INTEGRATION，附具体执行命令/步骤。
