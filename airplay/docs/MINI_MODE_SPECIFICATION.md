# AirPlay 迷你模式 (Mini Mode) 深度逆向规格说明书

本规范文档基于对 **AirPlay (Zion版) 原生可执行文件 (`AIRPLAY-zion_unpacked.exe`)** 的完整反汇编与资源解密逆向分析，详细记录迷你模式下的所有视觉要素、控件尺寸、渲染算法与交互特效。

---

## 1. 核心尺寸与几何布局 (Metrics & Layout)

在原版 AirPlay 中，迷你模式（Mini Bar）是一个独立无边框的分层透明窗口（Layered Window，窗口类名为 `FAIRPLAY GUI OBJEXT CLASS`，配置标识为 `window_main_mini`）。

### 1.1 窗口高度与玻璃边框尺寸
* **原版标准迷你模式高度**：**40 像素**。
  * **原版玻璃切片高度机制**：
    * 原版玻璃切片资源 `WINDOWGLASS` (及失焦版 `WINDOWGLASSFOCUS`) 的原始切片高度为 **40 像素**（宽 30 像素）。
    * 在正常面板模式下，顶部玻璃条高度为 **20 像素**（`sar edi, 1`，即 `40 / 2 = 20`，反汇编地址 `0x0047BB2F`），底部玻璃条高度为 **20 像素**，中间为内容面板。
    * **在迷你模式下**，面板内容区高度缩减为 0，**上下两个 20px 玻璃条直接紧密咬合在一起**，构成一个完整的 **40px 高度**水晶玻璃迷你条！
  * **紧凑型迷你模式高度**：**30 像素**（通过将上下玻璃条各截取 15px 或使用无圆角直角拉伸实现）。
* **左右玻璃边框厚度**：**5 像素**（反汇编地址 `0x0047DA6A`，返回常量 `5`）。
* **窗口默认宽度**：360 像素（可在 XML 配置中自由拉伸保存）。

### 1.2 为什么之前会出现“横向深色背景横条”？（根本原因分析）
通过逆向原版程序及对比先前代码，发现出现深色横条的根本原因在于：
1. **背景色填充与玻璃纹理通道混合错误**：
   * 原版 AirPlay 的迷你模式**完全不绘制不透明的深色底色矩形**，它的背景 100% 由 `WINDOWGLASS`（或 `WINDOWGLASSFOCUS`）切片的 32 位 ARGB 透明通道决定。
   * 在之前的代码实现中，在玻璃条渲染之前执行了 `FillRect` 或 `LinearGradientBrush` 填充深色底色（如 `rgb(23, 23, 23)`），而 Windows 的 `UpdateLayeredWindow` 在混合时将不透明底色与玻璃透明层叠加，导致出现了一条突兀的深色色带。
2. **直角 vs 圆角与上下玻璃条拼合**：
   * 原版将上下两个各 20px 的玻璃切片合二为一，由于 `WINDOWGLASS` 上半部分带有顶部高光，下半部分带有底部倒影与反光，合并后天然形成一个晶莹剔透的水晶棒质感，内部完全是半透明透光的，没有中间深色填充层。

## 2. 控件尺寸与精灵图切片 (Controls & Sprite Atlas)

迷你模式的所有控件图标来自解密后的资源精灵图 `MINICONTROL.png`（96×16，32位 ARGB）与 `WINDOWBUTTON.png`（130×26，32位 ARGB）。

### 2.1 播放控制按钮 (MINICONTROL: 96×16)
`MINICONTROL` 精灵图总尺寸为 96×16 像素，包含 6 个 16×16 像素的按钮图标：
| 按钮索引 | 像素切片 (X, Y, W, H) | 功能说明 | 窗口中垂直位置 |
| :--- | :--- | :--- | :--- |
| **0** | `(0, 0, 16, 16)` | 上一曲 (Previous) | `Y = 2px` (居中) |
| **1** | `(16, 0, 16, 16)` | 播放 (Play，暂停时显示) | `Y = 2px` (居中) |
| **2** | `(32, 0, 16, 16)` | 暂停 (Pause，播放时显示) | `Y = 2px` (居中) |
| **3** | `(48, 0, 16, 16)` | 停止 (Stop) | `Y = 2px` (居中) |
| **4** | `(64, 0, 16, 16)` | 下一曲 (Next) | `Y = 2px` (居中) |
| **5** | `(80, 0, 16, 16)` | 列表/菜单 (Menu) | `Y = 2px` (居中) |

* **按钮间距**：按钮之间水平间隔为 **2 像素**。
* **左侧起始边距**：左边框 5px + 4px 留白 = **9 像素**。

### 2.2 窗口控制按钮 (WINDOWBUTTON)
迷你条右上角包含窗口控制按钮，使用 `WINDOWBUTTON` 中的 13×13 像素切片（反汇编地址 `0x0047DA36`）：
* **关闭按钮**：13×13 像素，位于最右侧（右边框 5px + 4px 留白）。
* **最小化按钮**：13×13 像素，位于关闭按钮左侧 2 像素。

## 3. 控件交互效果与状态机 (Button States & Hover Effects)

原版通过反汇编代码 `0x004574DA` - `0x0045754E` 实现多级交互动画：
1. **常规状态 (Normal)**：
   * 控件图标以 **70% 不透明度 (Alpha = 180)** 混合渲染，呈现沉稳半透明的金属银灰色。
2. **鼠标悬停状态 (Hover)**：
   * 控件图标以 **100% 不透明度 (Alpha = 255)** 纯净白银高亮渲染，伴随边缘柔和的光学漫反射。
3. **鼠标按下状态 (Pressed)**：
   * 控件图标垂直方向 **向下偏移 1 像素**（模拟物理按键按压手感）。
   * 不透明度微调为 **90% (Alpha = 230)**。

## 4. 文字效果与紧凑字形光晕 (Typography & Glow Halo Effect)

### 4.1 字体与排版
* **曲目文字格式**：`歌名 - 歌手`（例如：`优质过客 - Single`）。
* **字号与样式**：9pt / 12px Segoe UI 或微软雅黑，抗锯齿 ClearType。
* **垂直对齐**：垂直完全居中。

### 4.2 Zion 原版紧凑光晕渲染算法 (Halo Algorithm)
原版反汇编函数 `0x0049B180` - `0x0049B240` 显示的文字特效并非简单的单一投影，而是**分层八向紧凑光晕算法**：
1. **暗色紧凑光晕层 (Halo Pass)**：
   * 光晕半径：**严格限制在 1 像素**（`dx = -1..+1, dy = -1..+1`）。
   * 光晕颜色：深黑色半透明 `rgba(15, 15, 15, 0.75)`。
   * 特点：光晕紧密贴合字形外缘，不向外扩散晕染，确保在透明水晶玻璃底板上文字具有极高的对比度与锐利度，绝不会模糊发虚！
2. **文字前景色层 (Foreground Pass)**：
   * 文字主色：纯白银灰 `rgb(235, 235, 235)`。

### 4.3 跑马灯滚动动效 (Title Scrolling Animation)
* 当歌曲名与歌手长度超过迷你条中间可用可视区域时，激活滚动定时器（反汇编定时器间隔 50ms）。
* 文字以每秒约 20 像素的平滑速度向左滚动。
* 当文字完全滚出左侧可视区后，右侧循环重新进入，留有 30 像素间隙。

## 5. 数字时间字体与进度显示 (TIMEFONT)

迷你模式的时间显示使用位图字体精灵 `TIMEFONT`（90×14 像素）：
* **字符尺寸**：每个字符宽 **6 像素**，高 **7 像素**（反汇编地址 `0x00457C26`）。
* **步长 (字符间距)**：**7 像素**（6px 字符 + 1px 间距，反汇编地址 `0x00457C85`）。
* **格式**：`MM:SS`（例如 `03:45`），占用宽度为 `5 * 7 = 35 像素`。
* **定位**：位于窗口右侧控制按钮左侧 8 像素处，垂直贴近玻璃下边框（`Y = panel_h - 9px`）。
* **交互特效**：点击时间区域可在“已播放时间”（`03:45`）与“剩余时间”（`-01:20`）之间切换。

## 6. 窗口拖拽、吸附与交互系统 (Window Interactions)

1. **全区域拖拽移动**：
   * 在迷你条任意空白玻璃区域按下鼠标左键即可拖拽窗口。
   * 在 `WM_LBUTTONDOWN` 命中测试若未命中具体按钮，立即调用 `SetCapture` 并跟踪鼠标位移直接移动窗口。
2. **任务栏边缘咬合吸附 (Taskbar Snap)**：
   * 逆向发现二进制中包含对 `Shell_TrayWnd`（Windows 任务栏）的直接检测（VMT 槽 23）。
   * 当迷你条拖拽至距离任务栏边缘 **15 像素**以内时，自动触发磁吸吸附，严丝合缝贴在任务栏上方或边缘。
3. **右键菜单**：
   * 右键点击迷你条弹出上下文菜单：
     * `切换至常规模式 (&N)`
     * `总在最前 (&T)`
     * `退出 AirPlay (&X)`
